# codebook
Codebook & Survey Tidier is the browser-based tool that turns messy survey exports (Google/Yandex/MS Forms) into a clean dataset, a documented codebook, and ready-to-run SPSS syntax – all processed locally in the browser, no data upload.
Codebook & Survey Tidier cleans up raw survey exports for researchers in the humanities and social sciences. Drop in a CSV or Excel file and it standardizes messy question-headers into valid variable names, splits "select all that apply" questions into analysis-ready 0/1 columns, flags data-quality issues (missing values, constants, mixed-language labels, "magic" missing codes), and generates a full codebook (Markdown), a Data Package JSON schema, and SPSS syntax with variable/value labels — plus a clean CSV ready for jamovi. Everything runs client-side; no file is ever uploaded to a server.
